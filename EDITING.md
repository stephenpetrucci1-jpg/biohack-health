# Editing the blog

Everything on biohackhealth.uk comes from the Markdown files in `content/`,
one file per article. You can edit those in the browser. You never need a code
editor or a terminal.

## Where

https://biohackhealth.uk/admin

Log in with the email and password from your invite.

## Writing an article

Click **New Article**. The fields are:

| Field | What it does |
| --- | --- |
| Headline | The title on the page and in the article list. |
| Google headline | What shows in search results. Under 60 characters. Leave blank to reuse the headline. |
| Standfirst | The sentence under the headline. |
| Google description | The grey text under the search result. Under 155 characters. Leave blank to reuse the standfirst. |
| Category | Research or News. Drives the filter buttons on the front page. |
| Author, Author role | Shown in the byline. |
| Date | Controls the running order. Newest first. |
| Cover image (upload) | Upload a wide image, around 1376x768. Resized and converted automatically. |
| Cover image (library) | Pick an existing image instead. Only used if nothing is uploaded. |
| Cover image description | What the image shows. Used by screen readers and by Google. |
| Evidence level, Evidence note | The grey box at the top of the article. Leave blank to omit it. |
| The short version | Three bullets at the top. Leave blank to omit. |
| Tags | Used to pick the three related articles at the foot of the page. |
| Position within the day | Only matters when several articles share a date. Lower shows first. |
| Article | The body. |

The URL comes from the headline, so changing a published headline changes its
address and breaks any existing links to it. Change the Google headline
instead when you only want the search result to read differently.

## Getting it live

Saving puts the article in **Drafts**. Nothing on the site changes.

Move it to **Ready** when it is finished. Stephen opens /admin, reads it, and
clicks **Publish**. The site rebuilds itself within a couple of minutes.

## Images

Uploaded covers are resized and re-encoded on the fly, so a large photo
straight off a camera is fine. Landscape works best. Anything close to square
gets cropped at the top and bottom on the article page.
